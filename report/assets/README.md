# Logo

Guarde aqui el logo de Cyberfusion como `logo.png`:

    https://cyberfusion.pe/wp-content/uploads/2024/11/Logo-Cyberfusion-2.png

La portada lo usa automaticamente. Si el archivo no esta, cae al
logotipo tipografico y el informe se genera igual.

Para la portada oscura conviene una version en blanco o sobre fondo
transparente. Si el PNG original tiene fondo claro, se vera un recuadro.
